# Simulaciones en MATLAB

Colección de simulaciones numéricas y modelos matemáticos desarrollados en MATLAB, junto con sus respectivos archivos de código y evidencias de ejecución.

# Estructura del Proyecto

El repositorio está organizado en los siguientes directorios:

`text
simulaciones-matlab/
├── codigos/     # Scripts y funciones fuente (.m) de las simulaciones
├── evidencias/  # Capturas de pantalla, gráficas y resultados obtenidos
└── README.md    # Documentación general del repositorio


* **codigos/**: Contiene los scripts principales y funciones desarrolladas en MATLAB para ejecutar cada simulación.
* **evidencias/**: Almacena las gráficas generadas, capturas de salida en consola y resultados visuales de las pruebas realizadas.
